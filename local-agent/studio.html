Si l’aperçu reste noir alors que le jeu est visible à l’écran, arrête la capture et essaie « Windows classique ».

En mode libobs, le son du bureau et le microphone sont capturés par WASAPI. Le mode FFmpeg exige « Stereo Mix » ou une entrée DirectShow équivalente pour le son du jeu. La voix passe par le microphone. Les deux sources sont mixées quand elles existent. Si Windows ne fournit pas Stereo Mix, l'application ne peut pas inventer une capture de son système : l'intégration libobs/WASAPI est l'évolution prévue.

Réduis SWAPP Live quand tu joues pour ne pas capturer l'interface. Évite d'afficher des données privées. La prévisualisation reste sur ton PC. Aucun direct public n'est lancé avant ton clic sur « Lancer le direct ». Pour utiliser tes scènes OBS, clique sur « Mode OBS ».
